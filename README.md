# UniFlow

Мобильное расписание и личные задания. Студент выбирает группу и подгруппу без регистрации. Даты, чётность недели и календарь используют Asia/Almaty (UTC+5).

Канонический адрес — https://xan-xz.github.io/schedule/, вход владельца — `/schedule/admin/` и `#/admin`. Исходники интерфейса находятся в `app/`, серверная модель и обработчики — в `backend/`. Сборка создаёт один артефакт `dist/`; подготовка выполняется локально и в закрытом CI.

Это рабочая ветка единого приложения. Новая сборка этого этапа ещё не опубликована, а весь выпуск 1.0 не объявлен готовым. Реальный вход владельца, доставка писем, устройства и открытые требования перечислены в [ограничениях](docs/LIMITATIONS.md) и [статусе выпуска](docs/RELEASE.md).

## Разработка

Нужны Node.js 22.19+ и npm.

```sh
npm ci
npm run dev
npm run lint
npm run format:check
npm test
npm run build
node scripts/check-retirement.mjs --dist
npm run budget
npm run test:e2e
```

Runtime — нативные ES modules без фреймворка и CDN. Административные инструменты загружаются отдельно. Публичный guest read доступен с localhost; приватные операции сохраняют проверку Origin опубликованного сайта. Локальные проверки входа используют закрытые HTTP fixtures.

## Данные и доступ

Источник — подтверждённое владельцем расписание исходного XLSX: 19 групп, 524 занятия, 133 исходные пары конфликтов и 54 замечания. Спорные данные сохраняются с provenance и не исправляются догадками. Подготовка нормализованного хранилища не переключает writer автоматически.

Единственный владелец — arappayevv@gmail.com. Вход требует пароль, независимое свежее подтверждение почты и TOTP. Пароль задаёт сам владелец; ключ Supabase не является паролем сайта. Сервер проверяет закреплённые UID, native session и TOTP factor. App credentials находятся в памяти вкладки.
