# Пара — расписание 06-057-25-11

Мобильный сайт с расписанием занятий группы **06-057-25-11**. Показывает текущую и следующую пару, время и аудиторию для выбранной подгруппы.

**Сайт:** https://xan-xz.github.io/schedule/

## Возможности

- Переключение между подгруппами **А** и **Б**: отдельные лабораторные, предметы и аудитории.
- Общие занятия отмечены как «Общая пара · А и Б».
- Просмотр всех дней текущей недели и возврат к сегодняшнему дню.
- Текущая пара определяется автоматически по времени Казахстана, `Asia/Qyzylorda` (UTC+5).
- Следующая пара, время до конца текущего занятия и индикатор его прогресса.
- Адаптивная вёрстка для телефонов и компьютеров.
- Сохранение выбранной подгруппы в браузере.
- Вход в локальный редактор через кнопку «Админ» и пароль.
- Проверка времени занятий и пересечений при сохранении.

## Как пользоваться

1. Открой сайт.
2. Выбери подгруппу А или Б.
3. Посмотри текущую пару либо выбери нужный день недели.
4. Кнопка «Вернуться к сегодня» возвращает расписание текущего дня.

Время на сайте рассчитывается для Казахстана, даже если устройство находится в другом часовом поясе. Часы устройства должны быть настроены правильно.

## Редактирование и хранение

Кнопка «Админ» открывает форму входа, после проверки пароля доступен редактор. В нём можно выбрать день и подгруппу, добавить или удалить занятия и изменить время, предмет и аудиторию.

**Сейчас изменения сохраняются только в `localStorage` текущего браузера.** Они не отправляются на GitHub и не меняют расписание у других посетителей. Выбор подгруппы также хранится локально. Очистка данных сайта удаляет эти настройки и локальные изменения.

Чтобы обновить исходное расписание для всех:

1. Измени данные в функции `demo()` внутри `index.html`.
2. Сохрани изменение в ветку публикации GitHub.
3. Дождись обновления GitHub Pages.

Если в браузере уже сохранено изменённое расписание, оно имеет приоритет над исходным. Для возврата к опубликованным данным удали ключ `para.06-057-25-11.v2` из локального хранилища сайта. Ключ `para.group` отвечает за выбранную подгруппу.

### Ограничение админского входа

Пароль проверяется в JavaScript на стороне посетителя; в коде хранится его SHA-256-хеш. Это блокировка интерфейса, которую можно обойти через инструменты разработчика. Она не является серверной авторизацией.

Для защищённого редактирования общего расписания нужны серверная проверка доступа и общее хранилище. GitHub Pages размещает статическую часть сайта; сервер можно подключить отдельно. Сам пароль в README не публикуется.

## Технологии и структура

Без фреймворков, сборки и внешних библиотек:

- HTML — разметка;
- CSS — оформление и адаптация к экранам;
- JavaScript — расписание, часы, переключатели и локальное хранение;
- Web Crypto API — проверка хеша введённого пароля;
- GitHub Pages — размещение.

`index.html` содержит всю разметку, стили и JavaScript. Это единственный обязательный файл для работы сайта.

## Локальный запуск

Скачай репозиторий. Для просмотра можно открыть `index.html` в браузере.

Для проверки админского входа используй HTTPS или локальный сервер на `localhost`, где доступен Web Crypto API. Например, если установлен Python, выполни из папки репозитория:

```bash
python -m http.server 8000
```

Затем открой http://localhost:8000/.

## Публикация через GitHub Pages

В настройках репозитория:

1. Открой **Settings → Pages**.
2. Выбери **Deploy from a branch**.
3. Укажи ветку **main** и папку **/ (root)**.
4. Нажми **Save**.

После изменения `index.html` GitHub Pages пересобирает сайт. Состояние публикации можно посмотреть во вкладке **Actions**.
