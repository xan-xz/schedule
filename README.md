# UniFlow

Мобильное расписание и личные задания. Студент выбирает группу и подгруппу без регистрации. Даты, чётность недели и календарь используют Asia/Almaty (UTC+5).

Канонический адрес — https://xan-xz.github.io/schedule/, вход владельца — `/schedule/admin/` и `#/admin`. Исходники интерфейса находятся в `app/`, серверная модель и обработчики — в `backend/`. Сборка создаёт один артефакт `dist/`; подготовка выполняется локально и в закрытом CI.

Версия приложения — 0.13.0. Весь выпуск 1.0 ещё не объявлен готовым. Опубликованный source commit определяется по /schedule/release.json и успешному production workflow. Реальный вход владельца, доставка писем, устройства и открытые требования перечислены в [ограничениях](docs/LIMITATIONS.md) и [статусе выпуска](docs/RELEASE.md).

Выбор группы доступен в первом HTML до запуска приложения. В «Ещё» настраиваются шесть палитр, четыре представления, размер текста, плотность и анимации; личные настройки работают офлайн. Владелец задаёт допустимые варианты интерфейса и сохраняет изменения расписания в устойчивые локальные черновики с явным восстановлением и отдельной публикацией.

Владелец управляет справочниками через поиск и черновик, видит зависимости удаления, может явно переназначить связанные записи, архивировать и восстановить группу или создать копию её метаданных. Публичная ссылка и QR открывают выбор группы без регистрации. Примечания к аудиториям и неизвестные служебные metadata не входят в публичные ответы и кэш.

В [редакторе звонков и типов](docs/TEACHING_SETTINGS.md) владелец создаёт варианты для форм без правки JSON. Они проходят черновик и отдельную публикацию; существующие времена и типы занятий сохраняются.

[Массовая правка](docs/BULK_LESSONS.md) меняет выбранные постоянные занятия через обязательный предпросмотр: кабинет, преподавателя, предмет, тип или время. Пакет атомарен, сохраняется в черновик и публикуется отдельно.

Студент сохраняет [личные задания и прогресс в файл](docs/PERSONAL_BACKUP.md) через «Ещё → Копия личных заданий» и восстанавливает их с предпросмотром, включая офлайн-режим. Уже существующие записи сохраняются, повторный импорт не создаёт дублей.

## Разработка

Нужны Node.js 22.19+ и npm.

```sh
npm ci
npm run dev
npm run lint
npm run format:check
npm test
npm run build
node scripts/check-retirement.mjs --dist
npm run budget
npm run test:e2e
```

Runtime — нативные ES modules без фреймворка и CDN. Административные инструменты загружаются отдельно. Публичный guest read доступен с localhost; приватные операции сохраняют проверку Origin опубликованного сайта. Локальные проверки входа используют закрытые HTTP fixtures.

## Данные и доступ

Источник — подтверждённое владельцем расписание исходного XLSX: 19 групп, 524 занятия, 133 исходные пары конфликтов и 54 замечания. Спорные данные сохраняются с provenance и не исправляются догадками. Подготовка нормализованного хранилища не переключает writer автоматически.

Единственный владелец — arappayevv@gmail.com. Вход требует пароль, независимое свежее подтверждение почты и TOTP. Пароль задаёт сам владелец; ключ Supabase не является паролем сайта. Сервер проверяет закреплённые UID, native session и TOTP factor. App credentials находятся в памяти вкладки.
