# Пара — расписание 06-057-25-11

**Сайт:** https://xan-xz.github.io/schedule/

Расписание группы с выбором подгруппы А/Б, текущей и следующей парой, аудиториями и общим редактированием.

## Возможности

- Отдельные предметы и аудитории для А и Б, общие занятия для обеих подгрупп.
- Дни недели, текущая и следующая пара, обратный отсчёт до конца занятия.
- Время Казахстана: `Asia/Qyzylorda`, UTC+5.
- Мобильная вёрстка.
- Общее расписание в Supabase.
- Обновления открытых страниц через Supabase Realtime.
- Повторное получение данных при возвращении на вкладку, восстановлении сети и каждые 15 секунд как резервный способ синхронизации.
- Серверная проверка админского пароля и ограниченные по времени сессии.
- Проверка пересечений времени и защита от перезаписи чужих свежих изменений.

## Как пользоваться

Открой сайт, выбери А или Б и нужный день недели. Подгруппа запоминается только на твоём устройстве.

Для изменения общего расписания:

1. Нажми **Админ**.
2. Введи админский пароль.
3. Выбери день и подгруппу.
4. Измени предметы, аудитории и время.
5. Нажми **Сохранить для всех**.

Изменение отправляется на сервер, после успешного сохранения другие открытые страницы получают обновление. Если два администратора одновременно редактируют расписание, устаревшая версия не перезапишет новую: редактор покажет сообщение. Скопируй нужные правки и открой редактор заново.

Кнопка **Выйти** завершает серверную сессию. Сессия также истекает через два часа; токен хранится только в памяти вкладки.

## Хранение и безопасность

Единый источник расписания — таблица `public.group_schedule` в Supabase. Старые локальные правки из предыдущей версии сайта больше не подменяют общее расписание.

В браузере сохраняются выбор подгруппы и последняя полученная версия расписания для просмотра при проблемах с сетью. При отсутствии связи общее редактирование недоступно.

Браузер может только читать таблицу через публичный publishable key. Прямая запись для ролей `anon` и `authenticated` запрещена. Запись выполняет Edge Function **schedule-admin** после проверки серверной сессии.

Пароль не включён в HTML/JavaScript сайта. На сервере хранится PBKDF2-SHA256 с индивидуальной солью; попытки входа ограничены. Сессионные токены сохраняются в базе как SHA-256-хеши. Служебные таблицы закрыты для посетителей с помощью прав доступа и RLS.

`SUPABASE_SERVICE_ROLE_KEY` используется только внутри Edge Function из переменных окружения Supabase. Его нельзя добавлять во фронтенд или репозиторий.

## Структура

- `index.html` — сайт, стили, редактор и клиент синхронизации.
- `backend/admin.mjs` — серверный вход, выход и сохранение.
- `backend/schema.sql` — схема таблиц, права, RLS, валидация и публикация Realtime.
- `README.md` — документация.

Клиент Supabase загружается в зафиксированной версии `2.95.0`. Если Realtime временно недоступен, остаётся периодическое чтение через REST API.

## Размещение

Статическая часть размещена на **GitHub Pages**: **Settings → Pages → Deploy from a branch → main → / (root)**.

Серверная часть размещена в **Supabase**, проект `Schedul`. URL и публичный ключ указаны в клиенте. Админская функция использует собственную проверку доступа; `verify_jwt=false` нужен для этой схемы, поскольку используется непрозрачная серверная сессия, а не Supabase Auth JWT.

Изменения расписания через сайт не требуют коммита или пересборки GitHub Pages. Изменения интерфейса в `index.html` публикуются через GitHub.

Для переноса в другой проект нужно отдельно применить схему, загрузить исходное расписание, настроить пароль и развернуть Edge Function. SQL-файл не содержит действующий хеш пароля или сессионные токены. Не запускай его повторно поверх существующей базы без миграции.

## Проверки

При подключении общей базы проверены:

- публичное чтение через REST;
- отклонение неверного пароля;
- вход с правильным паролем;
- отклонение сохранения без сессии;
- успешное серверное сохранение;
- клиентская синхронизация в модели двух открытых страниц;
- отказ при попытке сохранить устаревшую редакцию.

Полная визуальная проверка в реальном браузере в этой среде недоступна.
