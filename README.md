# UniFlow beta 2.0

Учебное пространство для студентов, преподавателей и администрации. Автор — Азат Араппаев.

**Сайт:** https://xan-xz.github.io/schedule/

**Попробовать без пароля:** [студент](https://xan-xz.github.io/schedule/?demo=student) · [преподаватель](https://xan-xz.github.io/schedule/?demo=teacher) · [администратор](https://xan-xz.github.io/schedule/?demo=admin).

Демо работает в отдельной песочнице и не меняет настоящую базу. Нажми «Настоящий сайт», чтобы выйти из демо. Для реального администрирования используй логин `admin` и ранее установленный пароль. Остальные аккаунты выдаёт администратор.

## Возможности

- Роли с серверной проверкой прав; группы и подгруппы, преподаватели, предметы, аудитории.
- Расписание по дням и неделям, чётные/нечётные недели, текущая и следующая пара.
- Назначения с проверкой занятости группы, преподавателя и аудитории.
- Отмены и переносы по датам; запрос преподавателя и решение администратора.
- Задания, дедлайны, личные отметки выполнения; журнал посещаемости.
- Адресные объявления и уведомления внутри сайта; Supabase Realtime.
- Аккаунты, отключение доступа, смена пароля; история и до 30 версий для восстановления.
- Поиск свободных аудиторий, нагрузка преподавателей, поиск и фильтры.
- Экспорт календаря на 28 дней, JSON и CSV; импорт с проверкой; печать и ссылки на группы.
- Мобильная вёрстка, тёмная тема, личные заметки, оболочка для добавления на главный экран.

## Инструкция

Подробные сценарии каждой роли и настройка настоящего пространства — в [GUIDE.md](GUIDE.md) и в разделе «Инструкция» на сайте.

Пример сценария: демо-админ меняет аудиторию → демо-студент видит изменение → преподаватель запрашивает перенос → админ согласует → изменение появляется на конкретную дату.

## Структура

- `index.html` — основной вход.
- `beta/app.mjs`, `beta/styles.css` — интерфейс.
- `beta/core.mjs` — общая валидация, права и операции; эта же логика развёртывается на сервере.
- `beta/demo.mjs`, `beta/seed.json` — отдельный пример с вымышленными участниками.
- `backend/uniflow-api.mjs` — Edge Function `uniflow-api`.
- `backend/uniflow-schema.sql` — исходная SQL-схема беты.
- `manifest.webmanifest`, `sw.js`, `icon.svg` — статическая оболочка приложения.

Статическая часть публикуется через GitHub Pages: `main`, `/ (root)`. Серверная часть — Supabase, проект `Schedul`. Изменения учебных данных не требуют коммитов. Изменения Edge Function требуют отдельного развёртывания; GitHub сам сервер не обновляет.

## Запуск локально

Из папки репозитория запусти любой статический HTTP-сервер, например при установленном Python:

```bash
python -m http.server 8000
```

Открой `http://localhost:8000/?demo=admin`. Демо работает локально. Сервер разрешает настоящий клиентский вход с домена `https://xan-xz.github.io`; для разработки настоящего входа понадобится явно добавить свой origin в серверный CORS.

## Доступ и данные

Пароли проверяются на сервере (PBKDF2-SHA256, 210000 итераций, индивидуальная соль). Токены сессий хранятся в базе как хеши, в браузере — только в памяти вкладки. Сессия действует два часа. Роли и активность аккаунтов проверяются на защищённых запросах.

Посетители читают разрешённое расписание через сервер. Приватные записи, аккаунты, пароли и версии закрыты правами доступа и RLS. Realtime передаёт только номер новой версии, затем клиент запрашивает разрешённые своей роли данные.

В браузер допускается только публичный publishable key. Секретные ключи, пароли и токены нельзя добавлять в исходники. Пароль главного администратора в документации не публикуется.

Настоящее расписание группы 06-057-25-11 перенесено с сохранением действовавших аудиторий. Неизвестные преподаватели не выдуманы — их должен назначить администратор.

## Проверки и границы беты

Пройдены проверки конфликтов, прав ролей, принадлежности заданий, согласования переносов и исключений по датам; серверные проверки реальных тестовых аккаунтов и запрета подстановки роли; запуск рендеринга HTML всех основных разделов трёх демо-ролей в тестовой среде. Временные проверочные аккаунты удалены.

Полная визуальная проверка в реальном браузере недоступна в этой рабочей среде. Пробный полный откат общих данных не выполнялся из-за ограничения автоматической проверки безопасности.

Уведомления работают внутри сайта. SMS, WhatsApp, email, фоновые push-рассылки, загрузка работ, оценки, автоматический подбор всего расписания и интеграция с системой университета не подключены. Отметка выполнения задания и личные заметки сохраняются на текущем устройстве.
