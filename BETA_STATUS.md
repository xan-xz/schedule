# UniFlow beta 2.0

Интерфейс и серверная часть подготовлены к публикации как согласованное обновление.

- [Демо администратора](https://xan-xz.github.io/schedule/?demo=admin)
- [Демо преподавателя](https://xan-xz.github.io/schedule/?demo=teacher)
- [Демо студента](https://xan-xz.github.io/schedule/?demo=student)
- [Инструкция](GUIDE.md)

Демо не требует пароля и изменяет только песочницу. Настоящий вход администратора — логин `admin`, ранее установленный пароль.

Проверены общая логика, ограничения серверных ролей и рендеринг основных разделов трёх демонстрационных ролей. Внешний вид в реальном браузере остаётся непроверенным. Полный пробный откат не выполнялся: автоматическая проверка отклонила такое восстановление без отдельного подтверждения. Прежнее действующее расписание сохранено при переносе.
