# API

HTTPS-функции проекта доступны под /functions/v1/. uniflow-api отдаёт guest projection и выполняет разрешённые мутации; uniflow-calendar формирует публичный календарь. Публичный apikey не является административной аутентификацией.

owner-access использует POST JSON и no-store. Полный контракт actions, TTL и восстановления — [OWNER_AUTH_PROTOCOL.md](OWNER_AUTH_PROTOCOL.md). Opaque credentials используют префиксы ow1c./ow1a./ow1r.; присланная роль или обычный JWT не выдаёт права владельца.

Запись требует проверенного actor, полной валидации и ожидаемой ревизии. Старый admin login/save закрыт; выдача второго admin запрещена. Guest ответы не включают аккаунты, посещаемость, password hashes и сессии. Native credentials и server keys не возвращаются интерфейсу.

Нормализованные import/export RPC являются закрытой service-only подготовкой; они не заменяют публичный CRUD и не переключают writer. Публичные guest state и preflight разрешают чтение с любого Origin. Защищённые операции проверяют точный Origin опубликованного сайта до обращения к данным; localhost Auth проверяется только закрытыми HTTP fixtures.

Каталоги используют тот же `action: "mutate"`, ожидаемый `revision` и проверенный opaque token владельца. Роль из JSON не даёт доступа. Поддерживаются `catalog.save {entity,item}`, `catalog.delete {entity,id}`, `catalog.replace {entity,id,replacementId}`, `catalog.duplicate {entity,id,name,code?}` и `group.archive {id,archived}`. `entity`: `groups`, `teachers`, `subjects`, `rooms`.

`catalog.save` принимает частичный набор авторских полей; существующий ID, положение записи и неизвестные метаданные сохраняются. Новая запись без ID получает UUID; явный новый ID поддерживает локальный черновик. Разрешённые поля:

| Каталог       | Поля                                                                                                                                       |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Группы        | name ≤80, code ≤80, specialty ≤160, language `ru/kk/en/""`, subgroups: 1–16 уникальных непустых строк ≤15, без `all` и окружающих пробелов |
| Преподаватели | name ≤160, subjects: уникальные существующие ID предметов                                                                                  |
| Предметы      | name ≤160, shortName ≤60, color `#RRGGBB`                                                                                                  |
| Аудитории     | name ≤60, capacity: целое 1–500, capacityEstimated: boolean, building ≤120, floor: строка ≤40, note: строка ≤1000 только для владельца     |

Неизвестные присланные поля отклоняются. Изменённые название/код группы и новый ID не могут совпадать с ID, кодом или названием другой группы: ссылки-приглашения должны оставаться однозначными. Неизменённые исторические псевдонимы не переписываются.

Чистая функция `catalogImpact(data,entity,id)` возвращает `{counts,total,blockers}`. `counts` содержит число связанных строк по разделам `lessons/exceptions/tasks/announcements/requests/attendance/holidays/teachers`; строка считается один раз в разделе, включая косвенную ссылку через lessonId. Учтены отменённые исключения, отклонённые заявки, прямые ссылки `groupId/teacherId/subjectId/roomId`, соответствующие массивы ID и назначения subjects преподавателей. Снимки `before/after` неизменяемы: blocker `{collection,id,path,reason:"historical_reference"}` не раскрывает их содержимое. Такие ссылки запрещают удаление и замену. Удаление используемой записи отклоняется, замена явно переназначает ссылки и сохраняет все связанные строки; несовместимые подгруппы и новые конфликты отклоняют всю операцию.

Копия получает новый UUID и только авторские метаданные, без неизвестных полей, исходного происхождения, архивного состояния и расписания. Код новой группы по умолчанию пуст; subjects копии преподавателя пусты. Архивирование ставит canonical `archivedAt`, восстановление — `null`; удалённые группы не восстанавливаются таким способом. Исторические строки и исходные предупреждения/разрешения конфликтов сохраняются. Архивная группа доступна владельцу для редактирования, но не занимает публичные календарные ресурсы. Старый календарный URL возвращает `200` с пустым корректным ICS, чтобы подписчик удалил прежние события. Восстановление проверяет активные конфликты. Публичный снимок может сохранять исторические строки; `lessonsForDate` и публичный календарь исключают неактивные группы. Core `occurrences` по умолчанию сохраняет их для владельца; `{activeOnly:true}` исключает их.

Публикация локальных замен через `import` передаёт отдельный `catalogReplacements:[{entity,id,replacementId}]`: максимум 100 прямых замен, без повторных источников, цепочек, циклов и дополнительных полей. Источник обязан существовать в свежем серверном снимке и отсутствовать в конечном каталоге; цель должна существовать в конечном каталоге, включая созданную в этом черновике запись. Сервер переназначает свежие приватные ссылки до наложения публичных каталогов. Переданные из браузера requests/attendance/tasks/announcements по-прежнему не заменяют серверные коллекции. Журналу черновика нужны только примитивные намерения, без приватных снимков. Перед CAS общая проверка не допускает потери групп/подгрупп/преподавателей, на которые ссылаются прежние аккаунты; аккаунты и их роли не изменяются.

`teaching.save {settings}` доступен только владельцу и сохраняет закрытое поддерево `siteSettings.teaching`. Формат версии 1:

```json
{
  "version": 1,
  "lessonTypes": [{ "id": "seminar", "name": "Семинар", "enabled": true }],
  "bellSchedules": [
    {
      "id": "day",
      "name": "Дневные звонки",
      "enabled": true,
      "slots": [
        { "id": "first", "name": "Первая", "start": "09:10", "end": "10:00", "endDayOffset": 0 }
      ]
    }
  ],
  "defaultBellScheduleId": "day"
}
```

ID: ASCII-буква/цифра, далее буквы, цифры, `_` или `-`, всего ≤100 символов. Названия обрезаются по краям: тип ≤40, сетка и звонок ≤80. ID и названия без учёта регистра уникальны в своём списке. Максимум 64 типа, 16 сеток, 1–32 звонка в сетке. Пустые списки типов и сеток разрешены. Основная сетка либо пустая строка, либо ID включённой сетки. Неизвестные поля и версии отклоняются. Интервалы `HH:mm`, offset 0/1, длительность >0 и ≤24 часов; пересечения в одной сетке, включая соседние сутки, запрещены, точные стыки разрешены.

Это варианты для форм, а не FK или правила пересчёта расписания. Изменение, выключение и удаление варианта не меняет материализованные `lesson.type/start/end/endDayOffset`, историю и исходные метаданные. При отсутствии настроек форма использует прежние 50-минутные варианты 08:00–21:50 только в памяти; чтение не создаёт конфигурацию в БД. Произвольные допустимые строки типов и интервалы остаются разрешены. Производные нормализованные `lesson_types/time_slots` по-прежнему вычисляются из занятий.

Старый JSON без `siteSettings.teaching` сохраняет текущее поддерево. Явно переданное поддерево проверяется и заменяется целиком; неизвестные соседние настройки на сервере сохраняются. Конфигурация владельца не включается в guest/student/teacher DTO, публичный кэш, bootstrap и seed.

`lesson.batch {ids,change}` доступен только владельцу, с обычным ожидаемым `revision` и серверной проверкой доступа. `ids` — 1–1000 разных существующих ID длиной ≤100, сравниваются точно. Одна операция меняет одно поле или один интервал:

```json
{ "ids": ["lesson-1", "lesson-2"], "change": { "kind": "roomId", "value": "room-2" } }
```

`change` имеет ровно один из форматов:

- `{kind:"roomId"|"teacherId"|"subjectId"|"type",value:string}`. Пустой roomId/teacherId явно снимает назначение; subjectId обязателен. Тип — непустая строка до 40 символов, без требования входить в варианты подсказок.
- `{kind:"setTime",start:"HH:mm",end:"HH:mm",endDayOffset:0|1}` — конкретный интервал с прежним днём и чётностью.
- `{kind:"shiftTime",minutes:integer}` — ненулевой сдвиг от −1439 до 1439 минут. Начало остаётся в исходном календарном дне; длительность сохраняется, сутки окончания пересчитываются. Переход начала на другой день отклоняется.

Неизвестные поля, повторные/отсутствующие ID и пустая правка отклоняются. Все патчи вычисляются до применения; затем весь кандидат проверяется один раз. Нельзя провести только часть пакета. Проверка предметов преподавателей, групп, подгрупп, пересечений, разовых изменений и исходных разрешений конфликтов совпадает с обычной моделью. `sourceConflictPairs` не переписывается и не пополняется. Сохранение source metadata и исторических снимков не является разрешением новых конфликтов.

Чистая функция `previewLessonBatch(data,payload)` возвращает `{valid,error,selectedCount,changedCount,unchangedCount,groups,changes}`. В `changes` только реально изменённые строки, с ID, группой/подгруппой и закрытыми `before/after` полями занятия. `groups[].count` считает изменённые строки. Происхождение из файла, неизвестные metadata, приватные коллекции и сессии в preview не входят. Невалидный кандидат остаётся предпросмотром с ошибкой и не применяется.

Меняются только регулярные `lessons`, в прежнем порядке и с прежними ID. Разовые `exceptions` и приватные исторические `before/after` сохраняются; они продолжают участвовать в проверке эффективного расписания. Отсутствующий нулевой offset и уже пустые назначения не нормализуются ради ложного изменения. UI сохраняет результат в обычные разрешённые дельты занятий; публикация остаётся отдельным `import` с CAS и свежими приватными коллекциями сервера. Нового механизма обхода черновиков или доступа не вводится.

Предел модели для занятий — 5000; остальные основные коллекции — 3000. Предел тела API — 2 МБ, выбора в одном пакете — 1000. Эти ограничения независимы: большой документ может раньше достигнуть лимита размера. Нагрузочные измерения не заменяют проверку конкретного устройства.
