# Производительность

Цели initial JS ≤60 КБ gzip и CSS ≤15 КБ gzip, точные CSP-хеши, отсутствие тяжёлых runtime/CDN зависимостей. Административный код загружается лениво; расписание не встраивается в исполняемый script.

Запуски: build, budget, perf на compiled артефакте. Количество Lighthouse запусков фиксируется заранее; берётся медиана без выбора лучшего. LCP ≤1000 мс и оценки 100/100/100/100 не считаются доказанными для новой ветки до измерения.

Прежние числа находятся в архиве и не переносятся как результат новой сборки. Отчёт содержит commit, окружение, все запуски и медиану. Скорость сериализации synthetic fixtures не является измерением throughput БД/API. Физические устройства проверяются отдельно.
