## Предупреждение, которое остаётся

`auth_leaked_password_protection`: встроенная проверка скомпрометированных
паролей выключена. [Supabase предоставляет её на Pro и выше](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection),
а текущая организация использует Free. Платный тариф автоматически не
подключается; предупреждение не скрывается. У UniFlow есть собственный
минимум 12 Unicode-символов, лимит 72 байта UTF-8, отдельное подтверждение
почты и TOTP, но это не равнозначно проверке базы утёкших паролей. Владелец
создаёт уникальный случайный пароль в личном менеджере паролей.

При переходе на подходящий тариф владелец может включить эту возможность
в Auth settings. Пароль, API keys и TOTP seed агенту для этого не передаются.
