# Проверка качества

## Среда и baseline

Browser plugin не установлен; применяется Playwright с Chrome/Chromium. Базовые скриншоты и отчёты созданы вне репозитория, в рабочем каталоге QA. Проверены 360×800, отсутствие ошибок JS и overflow; baseline accessibility перечислена в `PERF.md`.

## Автоматические проверки

- `npm run lint`: ESLint для нового кода плюс `node --check` всех модулей, включая legacy.
- `npm test`: чистая логика времени, данных и серверных прав; реальные данные не изменяются.
- `npm run test:e2e`: три viewport; deterministic API fixtures и demo, без реальных логинов/записей.
- `npm run build`: beta artifact; побайтовое сохранение прежнего корневого HTML.
- `npm run budget`: ограничение initial JS и CSS gzip.
- `npm run perf`: реальные лабораторные Lighthouse категории и метрики, JSON вне репозитория.

## Границы проверки

Прохождение тестов не доказывает развёртывание Edge Function, соответствие активной production RLS SQL-файлам или слияние двух источников расписания. Для этих операций нужны серверный доступ, бэкап и принятое владельцем решение о приоритете данных. Push при закрытом приложении, iOS install/permissions и внешняя ICS-подписка требуют отдельных интеграционных проверок; ограничения перечисляются в SECURITY/архитектурной документации.

Финальные результаты кандидата добавляются только после выполнения команд. Не заменять «не проверено» предполагаемым успехом.
