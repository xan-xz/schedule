# Справочники и группы

Раздел «Справочники» доступен после подтверждённого входа владельца. Поиск работает по названию и видимым сведениям. Для групп есть фильтр активных, архивных и всех записей.

## Редактирование

- Группа: название, стабильный публичный код, специальность, язык и список подгрупп. Изменение сохраняет идентификатор и неизвестные исходные метаданные; используемую подгруппу нельзя незаметно удалить.
- Предмет: название, короткое название, цвет `#RRGGBB`.
- Преподаватель: имя и назначенные предметы.
- Аудитория: количество мест или его оценка, подтверждённость вместимости, корпус, этаж. Примечание владельца не показывается студентам. Числовая оценка сама по себе не превращается в подтверждённую вместимость.

Любая правка справочника автоматически создаёт черновик. Применённые редактируемые поля сохраняются на устройстве. Отдельная кнопка «Опубликовать» отправляет проверенный черновик; закрытие формы и локальное сохранение ничего не публикуют. Если сохранение на устройстве недоступно, прежняя копия остаётся целой, а новые правки остаются в открытой вкладке до успешной повторной попытки.

После перезагрузки требуется повторный вход владельца и явное восстановление локальной копии. При изменении серверной версии восстановление показывает расхождения. Устаревшая публикация не перезаписывает новую версию.

## Архив, копирование и удаление

Архивирование группы сохраняет её идентификатор, расписание и связанные архивные сведения. После публикации группа скрывается из активного выбора студентов и расчёта ресурсов. Восстановление возвращает группу в активный выбор; исходные метаданные сохраняются. Удалённые исторические группы остаются недоступными для восстановления через обычное архивирование.

«Дублировать без расписания» создаёт новую запись только с редактируемыми метаданными. Расписание, задания, архивные данные и исходные ссылки не копируются. Публичный код новой группы задаётся отдельно; назначения нового преподавателя также заполняются отдельно.

Перед удалением показываются количества затронутых занятий, изменений по датам, заданий, объявлений, каникул, назначений и архивных записей. Неиспользуемая запись удаляется в черновике. Для используемой записи нужна конечная замена того же справочника; группы должны иметь одинаковые наборы подгрупп. Пересечения расписания блокируют замену целиком. Неизменяемые исторические ссылки блокируют удаление и замену; для группы можно выбрать архивирование.

Поддерживаются прямые замены исходной записи на конечную. Цепочки и циклы замен запрещены. Замену можно направить на запись, созданную в том же черновике. Локальный журнал хранит только узкие редактируемые поля и намерения замены `{entity,id,replacementId}`. Задания, объявления, посещаемость, заявки, полные серверные ответы и данные входа в журнал не сохраняются. При восстановлении и публикации ссылки переносятся на актуальных серверных данных, затем весь результат проверяется. Отдельная публикация обязательна.

Экспорт JSON в рабочем пространстве относится к расписанию; это не полная резервная копия частных данных или настроек входа.
