# Копия личных заданий

В разделе «Ещё → Копия личных заданий» можно скачать JSON-файл текущей группы и подгруппы. Он содержит личные задания и их прогресс. Храните файл в своём закрытом хранилище; экспорт работает офлайн после первого успешного посещения новой версии приложения.

На другом устройстве сначала выберите ту же группу и подгруппу, откройте инструмент и выберите файл. Проверьте количество добавляемых и уже существующих заданий, список по 40 строк, затем нажмите «Восстановить задания». Выбор файла сам ничего не сохраняет. Данные групповых заданий и серверного расписания в эту копию не входят.

Восстановление добавляет отсутствующие задания с новыми локальными ID и исходным прогрессом. Уже существующие задания сохраняют свои актуальные текст и прогресс. Повторное восстановление той же копии не создаёт дублей. После удаления восстановленного задания его можно добавить снова из файла. Изменение прогресса после восстановления имеет приоритет над исходной отметкой файла.

Технический предел — 1000 заданий на копию и в итоговом наборе текущей группы/подгруппы, файл до 1 000 000 байт UTF-8. Неверный формат, даты, дубли исходных ID и другой scope отклоняются целиком. Неизвестные поля файла не сохраняются. Восстановление использует одну локальную запись списка задач; прогресс новых записей хранится вместе с ними. Успех показывается после подтверждённого сохранения. При нехватке хранилища остаётся возможность повторной попытки; локальные задачи без сохранённого файла могут исчезнуть после очистки браузера.

Копия охватывает текущую группу и подгруппу. Для других выбранных групп/подгрупп создавайте отдельные файлы. Настройки оформления и локальный прогресс групповых заданий остаются на устройстве. Исчезнувший из справочника предмет сохраняет свой ID в личном задании; интерфейс показывает обычную подпись без предмета. Прогресс не переносится в серверную посещаемость или аккаунт владельца.

Файл относится к локальным данным пользователя и не является облачной синхронизацией или шифрованным архивом. Приватные ответы API, owner session, пароли и настройки доступа не экспортируются. Чтение и восстановление файла не отправляют задания на сервер. На русском, казахском и английском доступны одинаковые действия.
