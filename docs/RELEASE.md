# Состояние выпуска

8 ноября 2026. Версия 0.11.0: единое приложение из app/ с одним dist. Точный опубликованный source commit — /schedule/release.json, подтверждение публикации — успешные build/deploy/record-production. Серверная основа owner auth не означает готовность всего выпуска 1.0.

Реальные настройки Auth/SMTP, активация и положительный вход проверяются владельцем отдельно. Live-состояние может изменяться; синтетические Auth fixtures на используемом проекте не запускаются.

Перед публикацией требуются guard source/dist, переход адресов/worker/хранилища, сохранение личных данных, CSP, budget, unit/e2e, воспроизводимые метрики, immutable rollback и сверка данных. Совместимость ограничена compatibility.json. Локальная сборка ничего не публикует.

В 0.11.0 добавлены поиск и редактирование справочников, архив/восстановление групп, копии метаданных без расписания, проверка зависимостей и явные замены ссылок через черновик. Приватные связанные записи переназначаются на сервере по узким намерениям замены, а не по присланным массивам клиента. Исторические снимки не переписываются: удаление связанных записей блокируется. Архивные группы не занимают активные ресурсы и не формируют события в публичном календаре; восстановление заново проверяет конфликты. Ссылки и QR групп создаются локально и не дают прав управления.

Закрытая публичная проекция применяется к guest API, кэшу, bootstrap и seed. Неизвестные metadata и примечания владельца к аудиториям не выдаются гостям. Исправлена гонка редактирования во время отката. Палитры, четыре представления, локальные черновики и проверяемые immutable архивы из 0.10 сохраняются.

Нормализованная модель и переключение writer — отдельная работа. Адресные ревизии/откат, звонки/типы, XLSX review, поддержка и каналы доставки остаются открытыми. [План](RELEASE_1_PLAN.md), [ограничения](LIMITATIONS.md).

Итоговый отчёт заполняется после проверок на точном source commit; прежние unit/e2e/Lighthouse числа автоматически не переносятся.
