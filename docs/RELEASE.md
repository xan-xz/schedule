# Состояние выпуска

8 ноября 2026. Версия 0.10.0: единое приложение из app/ с одним dist. Точный опубликованный source commit — /schedule/release.json, подтверждение публикации — успешные build/deploy/record-production. Серверная основа owner auth не означает готовность всего выпуска 1.0.

Реальные настройки Auth/SMTP, активация и положительный вход проверяются владельцем отдельно. Live-состояние может изменяться; синтетические Auth fixtures на используемом проекте не запускаются.

Перед публикацией требуются guard source/dist, переход адресов/worker/хранилища, сохранение личных данных, CSP, budget, unit/e2e, воспроизводимые метрики, immutable rollback и сверка данных. Совместимость ограничена compatibility.json. Локальная сборка ничего не публикует.

В 0.10.0 добавлены настоящий выбор группы в первом HTML, шесть палитр, четыре представления расписания, настройки доступности и owner policy. Применённые изменения редактора сохраняются в локальных черновиках с поколениями, проверкой конфликтов и отдельным восстановлением; ввод в неподтверждённой форме не обещает autosave. Архивы будущих публикаций требуют provider lock, проверки обоих assets и совпадения source внутри TAR, manifest и Git tag.

Нормализованная модель и переключение writer — отдельная работа. Адресные ревизии/откат, полный CRUD/каскады, поддержка и каналы доставки остаются открытыми. [План](RELEASE_1_PLAN.md), [ограничения](LIMITATIONS.md).

Итоговый отчёт заполняется после проверок на точном source commit; прежние unit/e2e/Lighthouse числа автоматически не переносятся.
