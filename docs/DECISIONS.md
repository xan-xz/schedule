# Решения

- Один продукт app/, один публичный root и dist; подготовка локальная/CI без второго публичного контура.
- Исходный XLSX — источник владельца; 133 пары конфликтов и 54 замечания сохраняются с provenance.
- Единственный owner arappayevv@gmail.com; password/email/TOTP проверяет сервер. Пароль лично владельца, app credentials в памяти.
- Личные задачи и статусы локальны. Миграция browser storage ограничена известными ключами и сохраняет более новые значения.
- Нормализованный store аддитивен; payload lossless, entity/group/catalog revisions раздельны, writer не переключается неявно.
- Telegram — будущий второй клиент общих данных/прав/логики, без обхода owner auth и автоматической синхронизации личных задач устройства.
- Переход адресов/worker учитывается точным manifest; исторические требования и отчёты сохранены вне репозитория с SHA-256.
- Настоящие auth/delivery/devices и новые метрики остаются открытыми до фактической проверки.
