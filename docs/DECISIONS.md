# Решения

- **Vanilla ES modules.** Существующий проект статический; четыре простых student screen не требуют framework. Нативный DOM/textContent уменьшает XSS-поверхность, загрузку и число зависимостей. Node применяется только для проверок и упаковки.
- **Один продукт, разные задачи.** Четыре нижние вкладки для студента. Управление доступно из «Ещё» и грузится отдельным документом; профессиональные функции не попадают в начальный JS.
- **Сначала beta.** Корень и его данные не заменяются до сравнения источников. Ни одна sourceConflictPairs/исходная ячейка не исправляется молча.
- **Совместимая модель.** Сохраняем сущности и ID beta; новый слой проекции вычисляет occurrences, UTC+5, окна и ночные события. Новые optional поля не требуют destructive schema migration.
- **Офлайн и приватность.** IDB хранит гостевые snapshots и личные задачи; auth token только память. Cache API хранит только same-origin GET статику; POST API и чувствительные ответы не перехватываются service worker.
- **Обновления.** Без тяжёлого SDK на student path: conditional state polling при видимой вкладке и событии online. Сохранённый snapshot отображается сразу; сеть обновляет его. В демо сеть не изменяет рабочие данные.
- **Уведомления.** Notification API не умеет надёжно планировать при закрытом PWA. В первой версии напоминание при открытом приложении + ICS alarm. Push/VAPID требует отдельного серверного транспорта; без него UI не обещает push.
- **Языки.** Ключи ru/kk/en вынесены в словари, логика не содержит локализованных сравнений. Русский по умолчанию. Имена предметов из источника не переводятся автоматически.
- **Дизайн.** Нейтральный #f5f4fa, белая поверхность, один фиолетовый акцент, системный шрифт, центральная колонка до 720px, touch 44px, без декоративных иллюстраций. Главный экран начинается с текущей/следующей пары; настройки и роли в «Ещё».
