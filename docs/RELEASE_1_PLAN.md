# Требования 1.0

Оригинальные слова владельца, прежняя матрица и полный Telegram supplement сохранены с SHA-256 в history-6f75229 вне публичного репозитория. Этот список не объявляет требования выполненными.

1. Один продукт app/, публичный root, dist; сохранение рабочих данных устройств, ограниченный переход адресов/worker/ключей и строгий guard.
2. Единственный owner arappayevv@gmail.com; password + независимая свежая почта + TOTP, одноразовые setup/recovery, короткие сессии/revoke/аудит. Положительная реальная проверка обязательна.
3. Lossless нормализованная БД, FK/индексы, entity/group/catalog revisions, scoped write/rollback. Сохранить 524 занятия, ID/provenance, 133 спорные пары и 54 замечания.
4. Управление всеми группами, архив/дубль/QR, каталоги/звонки/типы, preview каскадов, разовые правки, шаблоны, import/export, черновик/autosave/история.
5. Устойчивый onboarding, ссылка группы, шесть палитр, четыре layout и owner policy; сохранить время/чётность/ICS/offline и личные задачи.
6. Поддержка без регистрации с receipt/статусом/вложениями/outbox, антиспамом и реальными двумя каналами владельцу. mailto не считается автоматической отправкой.
7. Telegram — второй полноценный клиент общей БД/auth/логики, с безопасной привязкой, уведомлениями, поддержкой и узкими owner-действиями. Полный план — TELEGRAM_CLIENT_PLAN.md; почта/Push отдельны.
8. Один проверенный артефакт, CSP, бюджеты, Lighthouse-медианы, CI без скрытых критических skip/flaky, immutable rollback и сверка данных после публикации.

Незавершённое остаётся в LIMITATIONS.md. Настоящие почта/TOTP/замена/откат/доставка и iPhone/Android/VoiceOver/TalkBack подтверждаются отдельно; mock и прошлый deploy их не доказывают.
