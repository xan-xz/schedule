# Импорт CSV с предпросмотром

Владелец открывает «Расписание → Импорт CSV» после обычного входа. Выберите файл UTF-8 до 1 000 000 байт и не более 1000 загружаемых занятий. Поддерживаются разделители запятая и точка с запятой, кавычки и переносы внутри кавычек. Файл читается локально и не отправляется при предпросмотре.

Обязательные столбцы: `day,start,end,subject`. Дополнительные: `room,teacher,type,subgroup,week,endDayOffset,id`. Другие и повторяющиеся заголовки отклоняются: данные неподдерживаемого столбца не будут молча потеряны. День — 0 (понедельник) … 6 (воскресенье), время — `HH:MM`, week — `all`, `odd` или `even`, endDayOffset — 0 или 1. Предмет, кабинет и преподаватель сопоставляются по ID либо названию из справочника; неизвестные и неоднозначные значения не угадываются. Пустые кабинет и преподаватель допускаются как неизвестные назначения.

Режим «Добавить занятия» оставляет существующие строки и добавляет новые, с общей проверкой ссылок, времени и пересечений. CSV с существующими ID требует режима «Заменить выбранную область». Этот режим заменяет собственные занятия выбранной группы и подгруппы; при «Все подгруппы» — все постоянные занятия группы. Для одной подгруппы общие занятия `all` и другие подгруппы сохраняются. Режим и область явно показаны до применения.

Для редактирования существующих занятий скачайте «Экспорт CSV» той же области, сохраните ID строк, внесите правки и выберите замену области. При совпадающем ID сохраняются provenance и неизвестные поля исходной записи. Отсутствующий в файле ID означает удаление строки выбранной области; предпросмотр показывает его отдельно. Связанные разовые изменения, задания, посещаемость и обращения автоматически не удаляются: нарушение ссылок блокирует импорт целиком. Изменённые занятия заново проходят общую проверку пересечений; новые разрешения исходных конфликтов не создаются.

Нажмите «Предпросмотр CSV»: появятся точные количества добавляемых, изменяемых, удаляемых и оставшихся без изменений занятий. Список «Было → Будет» разбит на страницы по 40 изменений; это только просмотр. Неверный файл и импорт без изменений не создают пустой черновик. Смена файла или режима сбрасывает просмотр. Если изменились группа, подгруппа, версия или черновик, откройте инструмент заново — устаревший файл не применяется к новой базе.

«Добавить в черновик» применяет весь проверенный набор локально. Дождитесь подтверждённого сохранения. При недоступном хранилище изменения остаются в памяти вкладки и доступна кнопка «Повторить сохранение»; она сохраняет текущий результат, не импортирует файл повторно. Предыдущая сохранённая копия остаётся доступной до успешной новой записи. Не закрывайте вкладку при ошибке без сохранённой копии. После перезагрузки нужен новый вход и явное восстановление локального черновика. Публикация на сервер выполняется отдельно кнопкой панели и проходит серверную проверку ревизии и прав.

CSV — текстовый формат, а не XLSX. Обработчик произвольного XLSX и review исходной сетки workbook остаются отдельной задачей. Этот инструмент не изменяет настройки доступа владельца, не решает неизвестные кабинеты/преподавателей исходного расписания и не является облачной резервной копией.


В 0.18.1 существующие ID сохраняют позиции в документе, даже если строки CSV переставлены. Новые занятия добавляются в порядке строк файла; отсутствующие собственные записи удаляются только в режиме замены области. Перед применением проверяется точное восстановление всех редактируемых разделов из локального журнала. Неподдерживаемые поля, снимки или порядок текущего черновика блокируют файл до изменения данных.

Если во время загрузки инструмента открыто другое окно или изменена группа/подгруппа, импорт не откроется поверх нового состояния. Откройте его повторно для нужной области. После ошибки хранилища «Повторить сохранение» сохраняет только проверенный применённый вариант; если черновик изменился, используйте его панель. Публикация остаётся отдельной.
