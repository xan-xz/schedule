# Выбор группы и сохранение данных

На первом посещении студент явно выбирает группу через поиск, затем подгруппу
или обе подгруппы. На повторном посещении сразу открывается «Сегодня».
Действительный выбор прежней версии переносится без повторного вопроса.

`?g=<ID или код группы>` предлагает подтвердить переход; существующий выбор
не заменяется без подтверждения. Старый параметр `?group=` поддерживается.
Если группа удалена/архивирована либо подгруппа исчезла, открывается выбор
с пояснением. Переименование при прежнем ID выбор не сбрасывает. Настройки,
личные задания и статусы прежней группы не удаляются.

Выбор сохраняется в localStorage и в публичном IndexedDB. Если оба хранилища
недоступны, расписание работает в текущей вкладке и показывает предупреждение.
Сохранение «навсегда» при удалении данных браузером или в инкогнито невозможно.
Офлайн-выбор использует уже сохранённый каталог; первый визит без сети и кэша
остаётся невозможным.

## Совместимость хранилища

- Основные записи: `uf.student.choice.v1`, `uf.student.settings.v1`.
- Резерв в IDB: `student-choice:live:v1`, `student-settings:live:v1`.
- Прежние ключи остаются читаемыми и поддерживаются для открытых старых вкладок.
- Массивы заданий и public snapshot в прежних ключах сохраняют исходный формат.
  Версия/время/отпечаток содержимого находятся в sidecar `__uf_meta_v1:<key>`;
  IDB меняет исходную запись и sidecar одной транзакцией.
- Более свежая локальная запись после неудачной IDB-записи не заменяется
  устаревшим содержимым. Изменение старой вкладкой без sidecar обнаруживается
  по отпечатку; при конфликте сохраняется резервная копия.
- Административные пароли, JWT, opaque credentials и списки аккаунтов этот
  модуль не хранит.

Проверки включают поиск/подгруппы, повторный запуск, IDB-only восстановление,
отключённые хранилища, offline, приглашение/отмену, переименование/архивирование,
удаление подгруппы и сохранение личных заданий. На 360/390/1280 проверены
доступность, отсутствие переполнения и чистая консоль.
