# Копирование и применение шаблонов

Владелец открывает «Расписание → Копировать день», «Копировать неделю» или «Шаблоны → Применить». Выберите исходный и целевой день/чётность; для шаблона дня — день назначения. Шаблон недели сохраняет свои дни.

1. Нажмите «Предпросмотр копирования». До него добавление отключено. Просмотр не создаёт черновик и не меняет общие данные.
2. Проверьте новые занятия: день, время, следующие сутки, предмет, кабинет, преподаватель, подгруппа, чётность и период действия. Большие наборы показаны по 40 карточек.
3. «Добавить в черновик» использует именно проверенные новые ID. Существующие занятия сохраняются. Изменение параметра отменяет прежний предпросмотр.
4. Дождитесь сообщения «Черновик сохранён на этом устройстве. Не опубликован». Для передачи студентам отдельно опубликуйте черновик.

Общие занятия при выборе одной подгруппы копируются только в неё. При выборе всех подгрупп сохраняются получатели исходных строк. Копирование недели переносит только занятия выбранной чётности; общие занятия уже действуют в обеих неделях. Шаблон обеих подгрупп с отдельными получателями нельзя незаметно сжать до одной подгруппы.

При пересечении, пустой исходной области, неверном направлении или отсутствующем справочнике весь набор отклоняется. Ошибка не создаёт пустой черновик. Разрешения исходных конфликтов и связи совместных занятий не переносятся на новые ID. Разовые изменения, задания, посещаемость и история не копируются.

До применения проверяется точное восстановление всех редактируемых разделов текущего черновика из локального журнала. Неподдерживаемые поля/снимки/порядок блокируют копирование. Данные остаются в прежнем состоянии; произвольный файл или шаблон не дают административных прав.

Смена группы/подгруппы, окна, сессии, ревизии, поколения или содержимого черновика отменяет устаревшее действие. Изменённый/удалённый локальный шаблон нужно открыть заново. Если локальная запись уже началась, закрытие формы не отменяет применённый черновик и не закрывает следующее окно.

При отказе хранилища предыдущая долговечная копия сохраняется, а проверенный результат остаётся в памяти вкладки. «Повторить сохранение» записывает те же ID без повторного копирования. Если содержимое уже изменилось, используйте панель черновика. До успешной записи не закрывайте вкладку. Локальная копия не является облачной синхронизацией; после перезагрузки для восстановления требуется повторный вход владельца.

Это добавление регулярных занятий. Замена занятого дня/недели, перенос существующих дат, автоматические каскады и канонические слоты этим экраном не реализованы.
