# Помощники UniFlow

## Telegram

В личном чате с ботом напишите «Какая следующая пара у группы 06-057-25-01?» или ответьте на карточку своего расписания вопросом «Что перенесли на этой неделе?». Поддерживаются запросы на русском и казахском. Бот берёт занятия, переносы и отмены из гостевого API UniFlow. Для общедоступного бота используется разбор вопросов по правилам.

## Кабинет владельца

- В «Расписании» откройте «Помощник расписания». При разовом переносе выберите исходную пару, дату переноса и возможные часы. Система сверяет занятость группы, преподавателя и аудитории и показывает подходящие варианты.
- В режиме «План факультета» выберите факультет, дни и время начала. Для большого расписания выберите одну группу. Расчёт ограничен сорока перемещаемыми занятиями за раз и сохраняет закреплённые занятия. Результат показывает изменения до внесения в черновик.
- После чтения листа XLSX включите «Подсказать соответствия столбцов». UniFlow сопоставит знакомые русские и казахские заголовки, а в предпросмотре покажет выбранные поля вместе с обычной проверкой расписания.

Помощник предлагает изменения. Владелец выбирает вариант, сохраняет его в черновик и отдельно публикует расписание.

## Локальная модель Bionic или LM Studio

Для необычных заголовков Excel доступна локальная модель через совместимый сервер Bionic или LM Studio. В Bionic включите Local Model API для загруженной локальной модели. Для LM Studio API работает на `127.0.0.1:1234`. Укажите точный идентификатор модели из `http://127.0.0.1:1234/v1/models` и запустите тестовую копию из PowerShell.

```powershell
$env:UNIFLOW_BIONIC_MODEL = "идентификатор-локальной-модели"
npm run dev -- --local-ai
```

Оставьте локальный процесс включённым и откройте рабочий кабинет владельца на этом же компьютере. При импорте XLSX включите «Подсказать соответствия столбцов» и «Использовать локальную модель Bionic». Браузер может попросить доступ к локальному серверу. Модели передаются только неизвестные названия столбцов и список допустимых полей. Значения ячеек обрабатывает обычный импорт.

[Локальный API Bionic](https://lmstudio.ai/blog/muse-glimmer) · [Структурированный ответ LM Studio](https://lmstudio.ai/docs/developer/openai-compat/structured-output)
