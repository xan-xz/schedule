# Данные

Владелец выбрал исходное XLSX-расписание единственным источником. Контрольный snapshot: revision 5, 19 групп, 524 занятия, 133 исходные пары конфликтов, 54 замечания. ID, ячейки, названия, кабинеты, часы и sharedSessionId сохраняются; спорные значения не угадываются.

app/seed.json содержит публичные назначения с provenance; bootstrap — публичный снимок выпуска с явным возрастом, обновляемый сервером. Аккаунты/сессии в эти файлы не входят. group_schedule этой подготовкой не удаляется.

Writer пока использует uf_platform. Нормализованный адаптер сохраняет точные payload, исходные ID и позиции; неизвестные поля/коллекции остаются lossless. Производные subgroup/slot/type проекции не подменяют источник. Обратный экспорт сверяется по JSON, счётчикам и checksum.

До реального cutover нужны приватный backup, изолированный dry-run, FK/ACL и rollback. Подготовка закрытого store не переключает writer и не меняет owner Auth.
