# Табличный XLSX: экспорт, редактирование и импорт

После входа владельца откройте «Расписание» и выберите группу и подгруппу. «Экспорт XLSX» скачивает собственные занятия этой области. При выборе одной подгруппы общие занятия `all` остаются вне замены. В файле два листа: «Расписание» для редактирования и «Справочники» с ID и названиями предметов, кабинетов и преподавателей. В расписании используются ID, чтобы одинаковые названия не меняли смысл ссылки. Заголовки закреплены, ширина столбцов настроена. Экспорт не содержит паролей, токенов, посещаемости и личных обращений.

Для нового файла откройте «Импорт XLSX → Скачать шаблон XLSX». Заполните лист «Расписание»: одна строка — одно занятие, заголовки в строке 1. Обязательны `day,start,end,subject`; дополнительные столбцы — `room,teacher,type,subgroup,week,endDayOffset,id`. День: 0 — понедельник, 6 — воскресенье. `week`: `all`, `odd`, `even`; `endDayOffset`: 0 или 1. Можно указывать точные ID или однозначные названия из текущих справочников. Пустые кабинет и преподаватель допустимы.

Время задавайте текстом `HH:MM` либо числовым временем Excel без даты и секунд. Числовой формат времени распознаётся; дата вместе со временем отклоняется. ID занятий и значения с ведущими нулями сохраняйте как текст. Числовой ID и форматированные числовые ссылки отклоняются, чтобы не терять отображаемые нули. Обычный целочисленный номер кабинета принимается. Формулы не вычисляются, даже при наличии сохранённого результата: замените их явными значениями. Строки, похожие на формулы или HTML, остаются текстом; при экспорте они записываются как текстовые ячейки.

Выберите файл до 1 000 000 байт, нажмите «Прочитать XLSX», явно выберите видимый лист «Расписание» и нажмите «Предпросмотр XLSX». Скрытые листы показаны с пометкой и недоступны для выбора. Данные других листов не объединяются автоматически. До 1000 занятий на выбранном листе, до 64 столбцов, номера строк до 10000. Пустые строки пропускаются, ошибки справочников указывают физическую строку Excel и название листа. Неизвестные и повторяющиеся заголовки, формулы, скрытые строки/столбцы, объединённые ячейки, ошибки ячеек, внешние ссылки, макросы, вложения и повреждённые книги блокируют импорт. Распаковка ограничивает фактический объём данных и проверяет контрольные суммы. Книга читается локально и не отправляется на сервер.

«Добавить занятия» сохраняет существующие строки и добавляет новые. Для обратной загрузки экспорта с ID выберите «Заменить выбранную область». Сохраняйте ID существующих занятий; для нового занятия оставьте ID пустым. Отсутствующий в файле ID собственной строки означает её удаление, которое будет отдельно показано в предпросмотре. При совпавшем ID сохраняются исходные сведения и дополнительные поля, а позиции существующих записей остаются прежними. Другие группы, другие подгруппы и общие занятия при замене одной подгруппы сохраняются. Связанные записи не удаляются автоматически; нарушение ссылок или новые пересечения блокируют весь файл.

Предпросмотр показывает количества и «Было → Будет», до 40 изменений на странице. Он ничего не сохраняет. Смена файла, листа или режима сбрасывает просмотр; изменение области, версии или черновика требует открыть импорт заново. Ошибка и отсутствие изменений не создают пустого черновика. «Добавить в черновик» сохраняет проверенный вариант локально. При ошибке хранилища «Повторить сохранение» повторяет только запись текущего результата, без повторного импорта. Дождитесь подтверждения сохранения. Публикация выполняется отдельно из панели черновика с серверной проверкой прав и ревизии. Правила восстановления и ограничений черновика общие с [CSV](CSV_REVIEW.md).

Это импорт таблицы занятий, а не распознавание произвольной сетки Excel. Исходная книга «2 курс КСиПО БАК 1 сем.xlsx» с восемью листами и объединёнными ячейками сохранена без изменения; её специальный разбор остаётся отдельной задачей. ZIP64, шифрование, OOXML Strict, старый `.xls`, `.xlsm`, бинарные части и XML не в UTF-8 не поддерживаются. Для сжатого XLSX нужен актуальный браузер с `DecompressionStream("deflate-raw")`; при отсутствии поддержки файл отклоняется с объяснением. Экспорт и шаблон используют обычный несжатый ZIP и не требуют распаковщика для обратного чтения.
