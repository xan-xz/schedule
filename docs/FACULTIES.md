# Расписание факультета в UniFlow

В кабинете владельца откройте «Справочники → Факультеты → Добавить». В строке факультета нажмите «Импорт XLSX факультета». Скачайте шаблон, заполните лист «Расписание», загрузите файл и выберите лист для предпросмотра.

На листе одна строка соответствует одному занятию. Обязательные столбцы — group, day, start, end и subject. В group укажите название, публичный код или ID группы. Для времени используется HH:MM, а day принимает значения от 0 для понедельника до 6 для воскресенья. Предметы, аудитории и преподаватели сопоставляются со справочниками по ID или однозначному названию. [Все правила табличного XLSX](XLSX_REVIEW.md).

Предпросмотр показывает добавление групп, назначение факультета существующим группам, а также добавление, изменение и удаление занятий. Файл заменяет расписание всех подгрупп перечисленных в нём групп. Остальные группы сохраняют своё расписание. Существующие группы другого факультета защищены от импорта. Разовые изменения, запросы и посещаемость сохраняются, а файл с нарушенными ссылками отклоняется.

Кнопка «Добавить в черновик» сохраняет сверенный результат. После отдельной публикации факультет и его группы доступны студентам. Группы из прежнего расписания на сайте и в Telegram отображаются под названием «Факультет бизнеса и цифровых технологий». В кабинете владельца они остаются без назначения, пока им не выберут факультет в справочнике.

## Telegram

Обработчик telegram-webhook читает опубликованное расписание через гостевой API UniFlow. В личном чате команды /start и /schedule открывают выбор факультета и группы, а /help показывает подсказку. Если в группе есть подгруппы, бот предлагает выбрать одну или посмотреть расписание всей группы. Кнопки «Сегодня», «Завтра» и «Неделя» перечитывают публикацию. Кнопка «Открыть на сайте» ведёт на выбранную группу и подгруппу. [Telegram Bot API](https://core.telegram.org/bots/api).

Кнопка «Связаться с администратором» и команды `/contact` и `/support` открывают контакты без выбора группы. Бот показывает почту для обращений и кнопку её копирования. Для кнопки «Написать в Telegram» укажите в Supabase Edge Secret `UNIFLOW_TELEGRAM_ADMIN_USERNAME` публичное имя аккаунта поддержки с `@` или без него. Ссылка открывает личный чат, где пользователь сам отправляет сообщение. [Кнопки Telegram Bot API](https://core.telegram.org/bots/api#inlinekeyboardbutton).

Для подключения рабочего бота разверните обновлённый uniflow-api и telegram-webhook. Храните TELEGRAM_BOT_TOKEN и TELEGRAM_WEBHOOK_SECRET в Supabase Edge Secrets. Приложение использует публичный ключ проекта из UNIFLOW_TELEGRAM_PUBLISHABLE_KEY или SUPABASE_ANON_KEY. Для webhook проверка JWT шлюзом отключается, поскольку сам обработчик проверяет заголовок X-Telegram-Bot-Api-Secret-Token. При регистрации через setWebhook задайте тот же secret_token и включите message и callback_query. [Конфигурация Edge Functions](https://supabase.com/docs/guides/functions/function-configuration) · [Регистрация Telegram webhook](https://core.telegram.org/bots/api#setwebhook).
