# Копия библиотеки шаблонов

Откройте панель владельца → **Расписание → Шаблоны**.

**Скачать копию шаблонов** сохраняет JSON всей библиотеки дня/недели. Файл содержит названия, область исходной группы, регулярные занятия и названия используемых справочников. Разовые изменения, рабочее расписание, черновики, личные задачи, история, настройки входа и секреты в него не входят. Неизвестные поля локальных записей не экспортируются. Распознаваемые строки доступа в названиях блокируют создание копии: сначала удалите их из названий.

Храните скачанный файл отдельно от браузера. Очистка данных браузера без файла удалит локальную библиотеку. Эта копия не является облачной синхронизацией или резервной копией всей платформы.

Чтобы перенести библиотеку, войдите владельцем в другом браузере, откройте **Импортировать копию шаблонов**, выберите JSON и нажмите **Проверить копию**. Файл проверяется локально и не отправляется на сервер. Предпросмотр показывает все шаблоны:

- **Добавить** — такого названия в библиотеке нет.
- **Уже есть** — название и содержимое совпадают; повтор не добавляется. ID и время создания не определяют совпадение.
- **Конфликт названия** — одноимённый шаблон отличается. Весь импорт блокируется, включая другие новые шаблоны. Переименуйте существующий шаблон или создайте копию с другим названием в исходном браузере, затем выполните проверку заново.

Названия сравниваются без различия регистра и с нормализацией Unicode. Повторяющиеся ID или названия внутри файла отклоняются. Существующие записи не заменяются и не удаляются. Новые шаблоны получают свежие ID.

После проверки отметьте **Подтверждаю добавление шаблонов в локальную библиотеку** и нажмите **Импортировать шаблоны**. Сам импорт не создаёт черновик и не меняет расписание. Для применения выберите шаблон отдельно, проверьте день и область, затем примените его в черновик и отдельно опубликуйте.

Исчезнувшие предметы, преподаватели или аудитории показаны предупреждением. Шаблон можно сохранить как копию, но применить к расписанию получится только после исправления справочников или создания нового актуального шаблона. Сопоставления по похожим названиям не выполняются автоматически. Пересечения, назначения преподавателей и подгруппы проверяются при применении к текущему полному черновику.

Пределы: JSON UTF-8 до **300 КБ**, библиотека до **20 шаблонов / 250 КБ**, до **100 занятий** в одном шаблоне. Повреждённый файл, неизвестные поля, недопустимые даты/интервалы и неполные ссылки отклоняются. Если общий предел превышен, удалите ненужные шаблоны самостоятельно после сохранения копии.

При нехватке места старая библиотека остаётся целой. Освободите место, снова проверьте файл и подтвердите импорт. При изменении библиотеки в другой вкладке или справочников требуется новое сравнение. Закрытие формы до получения блокировки отменяет ожидающую запись; позднее чтение файла не открывает форму заново.

Сохранение, переименование, удаление и импорт в текущей панели используют одну блокировку Web Locks. Если блокировка занята, ожидание ограничено четырьмя секундами; действие можно повторить. Браузер без Web Locks не записывает библиотеку, экспорт остаётся доступен. Старую вкладку, открытую до 0.17, нужно обновить: она не участвует в новом протоколе блокировки. [Документация Web Locks](https://developer.mozilla.org/en-US/docs/Web/API/LockManager/request).

Работа с библиотекой доступна после входа владельца. Реальный пароль, письмо и TOTP вводятся лично; автоматические проверки используют локальные HTTP fixtures. Синтетические Auth-записи и откат рабочих данных для проверки копии не нужны.
