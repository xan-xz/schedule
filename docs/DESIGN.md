# Дизайн и визуальная проверка

## Референс и границы сравнения

Концепт `outputs/design/uniflow-concept.png` — изображение 1706×922 с четырьмя состояниями: «Сегодня», «Неделя», «Задания», «Ещё». Это дизайн-направление, созданное для данной задачи, без отдельного этапа пользовательского утверждения: задание требует продолжать автономно.

Визуально просмотрены через `view_image` исходный концепт и реализации `candidate-360.png` (360×800), `candidate-390.png` (390×844), `candidate-desktop.png` (1280×900), `week-390.png`, `tasks-390.png`, `more-390.png`, `dark-390.png`, `demo-390.png`. Рендеры находятся в `outputs/screenshots/` итоговых материалов. Скриншоты получены Playwright: Browser plugin отсутствует в сессии.

Референс представляет четыре экрана на одной доске; приложение проверено отдельными viewport 360×800 и 390×844, а не по ширине всей доски. Сравнение подтверждает структуру и визуальную систему, но не заявляет попиксельное совпадение. Различия динамических данных намеренные: fixture показывает «Алгоритмы», аудиторию 204 и следующую пару в 205; демо при 17:10 Алматы показывает исходный предмет «Алгоритмдер және деректер құрылымы», аудиторию 1227, сохранённые имена и часы исходного расписания. Подменять данные ради сходства с концептом нельзя.

## Система

- Нейтральный фон `#f5f4fa`, белые формы и навигация, основной текст `#252231`, вторичный `#615b70`, разделитель `#d8d4e2`.
- Один акцент `#7044cc`, светлая поверхность текущей пары `#eee8fa`; акцент немного темнее исходного UniFlow `#7957d5` ради контраста.
- Тёмная тема: фон `#19171f`, поверхность `#24212d`, текст `#f4effb`, вторичный текст `#c0b7d0`, акцент `#c0a4ff`.
- Системный стек шрифтов, базовый размер 16 px, интерлиньяж 1.5; h1 32 px, заголовок текущей пары 22.4 px на мобильном, аудитория 40 px. Подписи и расписание 14 px. На широком экране увеличивается текущая пара, центральная колонка ограничена 720 px.
- Основные интервалы 8/16/24 px; мобильные горизонтальные поля 24 px. Радиус текущего блока 16 px, форм 8 px. У обычных строк нет карточек и теней.
- Нативные списки, time, progress, select, input и button; нижняя навигация содержит четыре текстовых пункта без декоративных иконок. Тач-цели не менее 44 px.
- Блоки недели используют липкий заголовок дня; нижняя навигация учитывает safe-area. Focus-visible имеет контрастный контур. Переходы 120 ms выключаются при prefers-reduced-motion.

## Журнал сопоставления

| Проверка | Концепт | Реализация / решение |
| --- | --- | --- |
| Главная задача | Предмет и крупная аудитория в начале | На 360 и 390 px предмет, аудитория, время, преподаватель, прогресс и следующая пара видны без перехода на другой экран. В fixture следующая пара начинается примерно на y=612 в 390 px viewport. |
| Навигация | Сегодня / Неделя / Задания / Ещё, активное подчёркивание | Те же четыре подписи и порядок, нижняя закреплённая панель, подчёркивание активного пункта. Роли доступны из «Ещё». |
| Типографическая иерархия | Бренд → название экрана → предмет → крупная аудитория | Иерархия сохранена. Длинное исходное название в демо переносится на две строки без обрезки; аудитория остаётся отдельным крупным элементом. |
| Цвет и контейнер | Белые экраны на нейтральной доске; светло-фиолетовая текущая пара | Приложение использует нейтральный фон целиком, а белый — для контролов и навигации. Это намеренное упрощение; карточка «Сейчас» остаётся единственным крупным цветным контейнером. |
| Метка «Сейчас» | Фиолетовая плашка | Простая фиолетовая подпись без отдельной плашки: меньше декоративных элементов по требованию пользователя. |
| Строки и окна | Открытый список с тонкими разделителями | Время в отдельной колонке, предмет и метаданные справа, тонкие разделители. Окно показывается перед следующей парой, к которой относится промежуток; длительность вычисляется из расписания. |
| Неделя | Переключатель недели, А/Б/обе, дни, липкие заголовки | Эти компоненты сохранены. Добавлено воскресенье, поскольку исходная модель допускает занятия во все семь дней. «К сегодня» следует заданию вместо подписи «Текущая» на концепте. |
| Задания | Кнопка личного задания, фильтр предмета, открытые строки и статус справа | Порядок и компоненты совпадают. В fixture одна настоящая тестовая задача вместо трёх нарисованных; добавлены описание и обозначение источника задания. Кнопки и select остаются нативными. |
| Ещё | Группа, подгруппа, язык, тема, формат, экспорт | Те же поля в том же порядке; перед группой добавлен необходимый поиск. Большие тач-цели и справочные тексты делают экран длиннее картинки: экспорт и напоминания доступны прокруткой, нижние вкладки остаются закреплены. |
| Постоянный контекст | Бренд/группа явно показаны на первом экране | Бренд и выбранная группа сохраняются на всех четырёх экранах, чтобы выбор группы был виден при переходах; крупных баннеров нет. Демо отмечено одной строкой в контексте группы. |
| Пустые и изменённые данные | Пример содержит отмену, замену и задания | При отсутствии соответствующих записей приложение показывает настоящее пустое состояние. Примерные отмены и задания из картинки не добавляются в рабочие данные. |
| Тёмная тема и десктоп | Отдельных состояний нет | Рендеры `dark-390.png` и `candidate-desktop.png` проверяют расширение той же системы: сохранены иерархия, порядок, отсутствие теней и ограниченная ширина. |

Копирование видимых подписей проверено по инвариантам: четыре вкладки, «Сегодня», «Сейчас», «Дальше», предмет, аудитория, время, прогресс. Подписи учебных данных, даты, длительности и наличие «Изменений» определяет модель, поэтому они отличаются от нарисованного примера. Раздел настроек намеренно включает поиск группы, установку и справочные ограничения, требуемые заданием, даже если они отсутствуют на доске.

В обычных viewport 360×800 и 390×844 просмотренные рендеры не показывают обрезки текущей/следующей пары или горизонтального переполнения. Проверка масштаба 200%, клавиатуры и разрешений мобильных платформ относится к автоматическому и интерактивному QA в `docs/QA.md`; визуальный просмотр отдельных скриншотов не заменяет эти проверки.

Исправленная деталь при сравнении «Заданий»: select статуса растягивался на всю высоту многострочного заголовка (~92 px). После `align-self:start` последний `tasks-390.png` повторно просмотрен через `view_image`: select имеет обычную высоту около 44 px и выровнен по началу строки.

## Локализация

Студенческий интерфейс содержит 99 явных ключей для ru/kk/en, включая подпись статуса для скринридера и подписку на календарь. Казахский и английский словари не наследуют русские значения через spread. Юнит-тест проверяет полный набор ключей и совпадение имён параметров подстановки. Совпадение русских и казахских слов «Аудитория», «Студент», «Демо» допустимо. Названия предметов и имена из источника сохраняются на исходном языке. Совместимый интерфейс управления пока русскоязычный; перевод словаря студента не означает перевод административных форм.
