# PWA

Manifest и публичный root относятся к одному приложению. Worker кэширует только публичную оболочку и guest данные. Password/native credentials/owner sessions и приватные ответы не попадают в CacheStorage, IndexedDB или browser key-value storage.

Старый worker может перехватывать навигацию до сервера, поэтому переход проверяется с прежней установки. Одного fallback HTML недостаточно. Разрешённые scope и retirement-workers перечислены в compatibility.json.

Миграция сохраняет рабочие settings/tasks/statuses/templates; более новые значения имеют приоритет. Удаление ограничено точными известными ключами. Нельзя использовать localStorage.clear, общий IndexedDB delete или удалять соседние caches на github.io.

Личные задания из прежнего контекста введены человеком: они объединяются с рабочей коллекцией, где совпавший ID сохраняет текущий текст. Переносятся только статусы доказанных личных заданий; статусы общего прежнего расписания не активируются. Исходный текст и неоднозначные статусы остаются в локальной recovery-копии. Старые IDB-записи удаляются только после устойчивой записи, проверки чтением и атомарной сверки неизменности в одной транзакции. localStorage не поддерживает межвкладочную compare-and-delete транзакцию: его прежние личные записи и completion-lists сохраняются как неактивные recovery-источники. При quota/отказе хранилища исходник остаётся для повторной попытки.

Offline/update проверяются и на compiled результате. Незавершённый административный черновик сохраняется до ручной перезагрузки. Фоновая доставка закрытой вкладки требует отдельного серверного канала; ICS его не заменяет.

Существующие документы сохраняют привязку к своей полной версии публичной оболочки. После перехода последней прежней вкладки новый клиент запрашивает очистку неиспользуемых root-кэшей; соседние scope и активные старые документы сохраняются. Retirement-регистрация снимает только себя после ухода своих клиентов.

Эта совместимость сохраняет уже загруженный административный черновик в памяти. Приватный инструмент, который старая вкладка ещё не загружала, после замены файлов может потребовать ручного обновления. Исторические приватные модули не имеют полных версионных URL; восстановление всех таких незагруженных инструментов не гарантируется.
