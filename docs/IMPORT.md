# Импорт

CSV использует day,start,end,subject,room,teacher,type,subgroup,week,endDayOffset,id; day — 0 (понедельник) … 6 (воскресенье). Справочники однозначно сопоставляются по названию или ID; неизвестные значения не подменяются похожими. [Импорт с предпросмотром](CSV_REVIEW.md) поддерживает добавление и явную замену выбранной области, показывает «Было → Будет» по 40 изменений и сохраняет результат в устойчивый локальный черновик. UI: UTF-8, до 1 МБ и 1000 загружаемых занятий. Публикация отдельна; устаревшая версия, непроверенный файл и неподдерживаемые локальной копией данные не применяются.

JSON импорт имеет [подробный предпросмотр](JSON_REVIEW.md) всех групп и отдельное подтверждение. До изменения черновика проверяется точное восстановление из локального журнала. Неподдерживаемые поля/перестановки, устаревшая версия и закрытая форма не применяются. Публикация отдельно проходит серверную проверку прав, ссылок, времени, пересечений и ожидаемой ревизии. Произвольный локальный файл не даёт административных прав.

Полный пользовательский XLSX parser с review ошибок и каскадами остаётся отдельным требованием. Исходный XLSX сохраняет provenance; поддержка произвольной загрузки не заявляется без обработчика.

Нормализованный импорт сохраняет payload, ID, positions, неизвестные поля, warnings и fingerprints. До cutover нужны dry-run и обратный экспорт с равными checksum/счётчиками. Приватные auth/session данные не входят в публичный экспорт.
