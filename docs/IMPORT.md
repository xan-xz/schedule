# Импорт

CSV использует day,start,end,subject,room,teacher,type,subgroup,week; day — 0 (понедельник) … 6 (воскресенье). Справочники сопоставляются по точному названию или ID; неизвестные значения не подменяются похожими.

JSON импорт проходит через черновик и серверную проверку прав, ссылок, времени, пересечений и ожидаемой ревизии. Preview не является записью. Произвольный локальный файл не даёт административных прав.

Полный пользовательский XLSX parser с review ошибок и каскадами остаётся отдельным требованием. Исходный XLSX сохраняет provenance; поддержка произвольной загрузки не заявляется без обработчика.

Нормализованный импорт сохраняет payload, ID, positions, неизвестные поля, warnings и fingerprints. До cutover нужны dry-run и обратный экспорт с равными checksum/счётчиками. Приватные auth/session данные не входят в публичный экспорт.
