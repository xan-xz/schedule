# Разработка

Нужны Node.js 22.19+ и npm; зависимости фиксирует package-lock.json. Используйте npm ci. Исходники — app/, сервер — backend/, проверки — tests/. Результат сборки один: dist/.

Перед PR выполните lint, format:check, unit, build, `node scripts/check-retirement.mjs --dist`, budget и браузерные сценарии. Playwright Chromium устанавливается командой `npx playwright install chromium`. Пробы провайдера используют изолированные fixtures; реальный owner login и доставка отмечаются отдельно.

Не меняйте боевые CORS/Auth/данные ради тестов. Синтетические Auth SQL probes запрещены на используемом проекте даже с ROLLBACK: там может идти личная настройка владельца.

Сохраняйте исходные ID, XLSX-координаты, sharedSessionId, замечания и fingerprints конфликтов. Запись проходит серверную авторизацию и полную валидацию. Индекс группы не заменяет проверку полномочий.

compatibility.json разрешает только конкретный путь и точную полную строку, без glob/regex исключений. Запрещённые названия нельзя маскировать конкатенацией или кодировкой. Секреты не попадают в source, fixtures, URL, screenshots и логи.

Локальный кандидат не является публикацией. PR описывает наблюдаемый результат, проверки и ограничения. Метрики измеряются заново после изменений; прошлые числа не выдаются за результат нового кода.
